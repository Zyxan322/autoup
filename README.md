# AutoUp — Premium Automotive Care Products & Essentials

AutoUp offers high-performance automotive detailing shampoos, waxes, exterior cleaners, and interior conditioners with seamless quotation via WhatsApp.

## Tech Stack

- **Framework**: TanStack Start (React 19)
- **Styling**: Tailwind CSS v4 & Glassmorphism design system
- **Routing**: TanStack Router (File-based)
- **Animation**: Embla Carousel React & Tailwind CSS Animate
- **Icons**: Lucide React
- **Build Tool**: Vite & Nitro

## Local Development

```sh
npm install
npm run dev
```

The application will be running locally at `http://localhost:8081` (or next available port).

## Production Build & Tests

```sh
# Run Vitest test suite
npm run test

# Build for production
npm run build
```

## Vercel Deployment

This repository is configured for deployment on [Vercel](https://vercel.com):

1. Import this repository in your Vercel Dashboard (`https://github.com/Zyxan322/autoup.git`).
2. Build Command: `npm run build`
3. Output Directory: automatically generated by Nitro (`.output/public` / `.vercel/output`).
